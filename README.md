# 初中体育成绩自动评分与统计分析系统

一个无需安装前端依赖的响应式网页工具，适合在电脑和手机浏览器中使用。它可以录入初中体测原始成绩，计算单项分、加权总分和等级，并按班级统计平均分、优秀率、优良率、及格率和等级分布。

## 已实现功能

- 录入姓名、班级、年级、性别、成绩状态和附加分。
- 支持 BMI、肺活量、50 米跑、坐位体前屈、立定跳远、力量项目、耐力项目。
- 根据性别读取不同评分档位，自动计算单项分、权重折算分、总分和等级。
- 缺考、免测、缺项记录会保留，但不会进入优良率和及格率分母。
- 支持姓名/班级搜索、查看、编辑、删除。
- 支持 CSV 批量导入和导出。
- 支持按班级查看平均分、优秀率、优良率、及格率和等级分布。
- 评分标准通过 JSON 配置，可按地区、年份、年级和性别替换。
- 数据默认保存在当前浏览器的 localStorage 中。

## 本地运行

项目是纯静态网页，使用任意静态服务器即可运行。例如在项目根目录执行：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

也可以把仓库发布到 GitHub Pages，直接使用生成的站点地址。

## 评分标准说明

仓库中的 `standards/demo-standard.json` 和 `src/score-engine.js` 内置的是演示评分表，只用于验证程序流程，**不代表国家标准、当地中考标准或学校正式标准**。初中体育评分会因为地区、年份、年级、性别和考试类型而不同，正式使用前请在“评分设置”中替换成学校确认的标准。

JSON 主要字段如下：

- `weights`：项目权重，通常合计为 100。
- `events.<项目>.direction`：`higher`、`lower` 或 `range`。
- `events.<项目>.male` / `female`：评分档位。
- `gradeBands`：总分等级起始分。

## CSV 导入列

首行可使用下面的中文列名：

```text
姓名,班级,年级,性别,状态,BMI,肺活量,50米跑,坐位体前屈,立定跳远,力量项目,耐力项目,附加分
```

其中耐力项目统一用秒填写，例如 4 分 20 秒填写 `260`。男生力量项目默认解释为引体向上、耐力项目默认解释为 1000 米跑；女生分别解释为仰卧起坐和 800 米跑。
